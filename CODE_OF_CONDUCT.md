# Code of Conduct

HandyWeb follows the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

In short: be respectful and welcoming to everyone, in Persian and in English. Harassment, insults, and personal attacks are not accepted in issues, pull requests, or any other project space.

To report a problem, contact the maintainer privately through the GitHub profile https://github.com/radestsam. Reports are handled in confidence.
