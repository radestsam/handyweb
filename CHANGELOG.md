# Changelog

All notable changes to HandyWeb are listed here. The project uses [Semantic Versioning](https://semver.org/).

## Unreleased

### Added

- Static site with Persian (RTL) and English (LTR) pages, light and dark themes, and self-hosted Noto Sans and Estedad fonts.
- Tool registry, runtime, worker protocol, and file helpers.
- Base64 Encoder and Decoder.
- JSON Formatter and Validator.
- SHA-256, SHA-384, and SHA-512 Hash Generator for text and files, plus MD5 and SHA-1 with a legacy warning.
- Persian Text Normalizer and Digit Converter.
- Jalali and Gregorian Date Converter.
- Word and Character Counter.
- Case Converter (UPPERCASE, lowercase, Title Case, Sentence case).
- Remove Duplicate Lines.
- Sort Lines Alphabetically, with Persian alphabetical order and natural number order.
- Text Cleaner, with a Persian preset.
- URL Encoder and Decoder, for one part of a URL or a full URL.
- HTML Entity Encoder and Decoder.
- Unicode Escape and Unescape.
- Unicode Character Inspector.
- XML Formatter and Validator.
- JWT Decoder, with a clear note that it does not verify the signature.
- HMAC Generator and Verifier.
- Password and Passphrase Generator, with the EFF large wordlist.
- Random Token and Bytes Generator.
- UUID and ULID Generator, with an inspector for the version and the time.
- Text Diff Checker, by lines, words, or characters, with a unified patch.
- Regex Tester, with a time limit and a warning for slow patterns.
- Unix Timestamp Converter, with Jalali dates.
- Number Base Converter, for bases 2 to 36 with exact large numbers.
- QR Code Generator, with PNG and SVG download.
- Reverse Text, Text Repeater, and Text Splitter and Joiner.
- Find and Replace, with plain text and regex modes.
- JSON String Escaper and Unescaper.
- Slug Generator, with Latin and Persian slugs.
- Lorem Ipsum Generator, with Persian placeholder text.
- Email, URL, and Phone Extractor.
- Number to Persian Words, with decimals, ordinals, and Rial or Toman.
- Persian Half-Space (ZWNJ) Fixer.
- Persian Punctuation Fixer and Persian Text Direction Fixer.
- YAML Formatter and Validator, and JSON and YAML Converter.
- SQL Formatter for six dialects.
- HTML, CSS, and JavaScript Formatters.
- JSON and CSV Converter, with an Excel-friendly download.
- JSON Diff.
- JSON Schema Validator.
- Color Converter, with WCAG contrast.
- URL Parser and Inspector, with warning signs for deceptive links.
- Cron Expression Parser.
- HTTP Header Parser, with a security header check, and User-Agent Parser.
- Text to Hex and Text to Binary Converters.
- File to Base64 and Data URI.
- Gzip and Deflate Compressor.
- Subtitle Converter (SRT and VTT), with time shift and Windows-1256 repair.
- Text Encryption with a Passphrase (AES-256-GCM, PBKDF2).
- TOTP Code Generator.
- File Type Detector.
- Certificate and CSR Decoder.
- HTML Previewer in a sandboxed frame.
- Markdown Editor and Preview, with sanitized HTML.
- Image Resizer, with a size check before decoding.
- Image Rotator and Image Flipper.
- Image Cropper with aspect ratios.
- Image Converter (PNG, JPEG, WebP).
- Image Compressor, with a warning when the result is larger.
- Image Metadata Viewer and Remover (lossless, checked by reading the output again).
- Image Color Picker.
- Image Palette Extractor.
- Image Comparer (slider, opacity, and pixel difference).
- Image Blur Tool, for the whole picture or one area.
- Image Pixelator, for the whole picture or one area.
- Image Watermark Tool (Persian or English text, or a logo).
- Favicon Generator (ICO, Apple and app icons, manifest, and HTML in one ZIP).
- SVG Viewer and SVG to PNG, with unsafe parts removed.
- SVG Optimizer.
- Unit Converter, with Iranian units.
- Percentage Calculator.
- Discount Calculator.
- VAT Calculator, with a rate that the user enters.
- Date Difference Calculator for Persian (Jalali) and Gregorian dates.
- Aspect Ratio Calculator.
- Image Resolution and Print Size Calculator.
- CSS Unit Converter.
- Roman Numeral Converter.
- Binary and Hex Calculator.
- Color Contrast Checker (WCAG).
- Time Zone Converter (uses the time zone data of the browser).
- Barcode Generator (Code 128, EAN-13, EAN-8, UPC-A).
- QR Code and Barcode Reader (camera or picture).
- IP Subnet Calculator for IPv4 and IPv6.
- MAC Address Formatter.
- HTTP Status Code Reference, with its data source in `docs/reference-data.md`.
- MIME Type and File Extension Lookup.
- Private and Reserved IP Ranges reference.
- QR Code Generator: Wi-Fi, email, and contact (vCard) forms.
- PDF Merger, with reordering. The PDF library loads only when a PDF is opened.
- Images to PDF (JPEG, PNG, WebP, GIF, BMP), with A4, Letter, or image-sized pages and margins.
- Installable app (web app manifest per language) and a service worker that keeps the site and opened tools working offline.
- About, Privacy, Open Source, and Contribute pages.
- Privacy, accessibility, and end-to-end tests.
